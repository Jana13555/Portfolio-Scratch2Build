# Scratch2build Week #4 - Assignment #2

Personal interactive portfolio built from scratch with HTML, CSS and vanilla JavaScript as part of the scratch2build program (Week 4).

## Features
- Semantic HTML5 layout (`header`, `nav`, `main`, `section`, `footer`)
- Responsive design with CSS Grid and Flexbox (no horizontal overflow)
- Dark / Light theme toggle saved in `localStorage`
- Project category filter that remembers the active category
- Contact form with client-side validation

## Tech Stack
HTML5 · CSS3 · JavaScript (ES6+) · Git & GitHub

## Project Structure
- `index.html` — page structure
- `styles.css` — styles and responsive layout
- `app.js` — interactivity and `localStorage` logic
- `.github/pull_request_template.md` — template used for every Pull Request

## Run Locally
1. Clone the repo: `git clone https://github.com/<your-username>/scratch2build-portfolio.git`
2. Open `index.html` in your browser.

## Git Workflow
- `main` is never pushed to directly.
- Every feature lives on its own `feature/*` branch with small, descriptive commits.
- Changes reach `main` only through a Pull Request.
